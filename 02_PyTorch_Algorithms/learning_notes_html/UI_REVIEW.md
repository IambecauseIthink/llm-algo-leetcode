- 75 个正式课程统一为中文主标题、紧凑目录、分段阅读布局；删除重复大标题与整段 Notebook 原文堆叠。

## 后续维护

修改 `teaching_specs.js`、`advanced_course.js`、`assets/learning_lab.js` 或生成器后，执行 `npm run generate` 与 `npm test`。升级官方版本时先更新 Git upstream，再调整 `upstream_source.json`、映射及讲义。发布前执行 `npm run check:notebooks`；检查的是暂存区，个人 Notebook 可以留在本地工作区，但不能加入提交。
