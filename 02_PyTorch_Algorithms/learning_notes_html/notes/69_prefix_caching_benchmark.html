模型与 backend 固定版本 与 G0 相同
batch / concurrency 固定 与 G0 相同
唯一变量 cache off prefix cache policy
命中证据 不适用 backend metrics、日志或专用接口

Step 3: 用统一口径比较收益与代价

命中率不是最终目标。每组结果至少要同时记录：

指标组 字段 判断问题
复用 hit rate、reused tokens、prefill work reduction 重复计算减少了多少
性能 TTFT、TPOT、E2E、throughput、P99 请求链路是否真正变快
资源 peak memory、cache blocks、eviction 缓存维护是否带来额外压力
质量 status、task quality、OOM 是否保持同一输出约束

Step 4: 输出 benchmark 决策

决策 条件 下一步
accept 命中率达标，TTFT/吞吐有稳定收益，维护代价可接受 扩大请求量和并发回归
tune 命中率达标但收益不稳定，或 chunk/失效策略仍需调整 改变单一变量后重跑
reject 命中率不足、代价过高、OOM 或无端到端收益 关闭缓存或更换 workload
