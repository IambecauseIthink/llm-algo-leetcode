图解原理

Checkpoint 用重算换存储，offload 用搬运换存储。不同 workload 的重算量和传输能力不同，不能预先宣布一种方法总赢。

先认识这三个词

checkpoint
保存少量检查点，反向时重建需要的激活。
offload
暂存到主机，反向前取回。
combination
在不同区域搭配策略，收益与开销不一定简单相加。

Mission 2 02 / 操作与推演

把一个小例子算到最后

图解原理

先用默认数值手算，再只改一个参数。让结果来检验你的猜想。

  1. 同一基线

    固定模型、batch、长度、dtype 和质量口径，分别测试三种候选。

  2. 课堂比较

    若重算代价 1.5 秒，8 GiB 往返、带宽 8 GiB/s 的搬运代价 2 秒，时间上重算较少。

  3. 检查实际峰值

    策略可能引入临时缓冲，节省必须按真实峰值看。能重叠多少也需要时间线证据。

动手实验室 / 只在浏览器中演示

腾空间之前，先算一趟往返

改变搬运量和有效带宽，与 1.5 秒的假设重算比较。

教学简化模型：所有数值来自上方规则，不是 GPU 性能实测。播放可以暂停，键盘方向键可调整滑块。

Mission 3 03 / 纠错与迁移

从会看，走到会写与会判断

图解原理

下面是一段独立的小练习。它把计算关系写清楚，帮助你进入官方题目；不是整份作业的答案。

读懂这段最小 Python

recompute_s = 1.5
offload_s = 2*8/8
print(min(recompute_s, offload_s))  # 1.5, serial toy model

先找输入变量，再找中间量，最后核对注释里的输出。改一个输入，手算后再运行。

最容易踩的坑

不同策略使用不同长度或 batch，然后把更低显存都归于策略；或者把 CPU 模拟当 GPU 实测。

去官方题目做什么

  1. 到官方 Notebook 阅读题目函数与测试；先写出输入、输出和一个最小例子。
  2. 把本课手算过程转换成实现，先跑最小测试，再检查空输入、边界值或未达门槛的情况。
  3. 记录一个与预期不同的结果，并用本课术语说明原因。
